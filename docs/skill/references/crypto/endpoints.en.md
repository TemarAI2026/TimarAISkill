# Crypto Endpoints Reference

## Endpoint Table

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/api/v2/digital/payments` | Create a payment order. |
| `GET` | `/api/v2/digital/payments/{orderId}` | Query a payment order. |
| `POST` | `/api/v2/digital/payments/{orderId}/cancel` | Cancel a payment order. |
| `POST` | `/api/v2/digital/payouts` | Create a payout order. |
| `GET` | `/api/v2/digital/payouts/{orderId}` | Query a payout order. |
| `GET` | `/api/v2/digital/balances` | Query account balances. |
