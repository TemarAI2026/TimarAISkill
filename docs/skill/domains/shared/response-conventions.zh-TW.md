# 回應慣例

## 標準包裝結構

所有公開回應都使用相同的頂層包裝：

```json
{
  "code": "0",
  "msg": "",
  "data": {}
}
```

穩定的包裝欄位是 `code`、`msg`、`data`。

## 成功與失敗判讀

- `code == "0"` 代表請求成功。
- 其他任何 `code` 都代表請求失敗或需要處理。
- `msg` 提供可讀的結果或錯誤訊息。
- `data` 在成功時承載業務資料，失敗時通常為 `null`。

## 支援與除錯說明

請一併記錄回傳的 `code`、`msg` 與你的 `X-Api-RequestId`。Request ID 是支援或工程團隊追查單筆請求最快的線索。
